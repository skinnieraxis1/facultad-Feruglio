# Diagrama de casos de uso
## Elementos del diagrama
### Actor
Aquel que utilizará el sistema, operador, alumno, ayudante, etc. <br>
Un actor puede tener multiples roles, para cada uno crearemos un nuevo actor. Puede ser software, persona, hardware, etc todo lo que genere un INPUT externo

### Caso de uso
Son la descripción de un conjunto de secuencias de acciones que ejecutará el sistema.

Nombre de actor al sistema: Que es lo que hace el actor con el sistema (Ingresar reserva) (Retirar dinero)

### Plantilla
Descripción específica de cada caso de uso, donde involucramos todos los pasos y el detalle real
