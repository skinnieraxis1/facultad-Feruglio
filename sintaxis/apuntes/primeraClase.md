## ¿Qué es programar?

 Código -> compilador -(Mnemónicos)-> Assembler -> Opcode

# Tipos de lenguajes
- Lenguaje -> Comunicación y planeación pensado a futuro
- Lenguaje de programación -> Forma de interacción con la maquina para ##definir un comportamiento##
- Lenguaje de máquina / bajo nivel (Específico de cada sistema / No portable):
    1. Lenguaje de bajo nivel
    2. Opcode en Binario
    3. Opcode en Decimal
    4. Opcode en hexadecimal
    5. Mnemónicos en lenguaje assembler -> traduce mnemónicos a opcode para el entendimiento de la computadora (Ensamblador)
- Lenguaje de alto nivel (Portable / Globalizado)
    1. C++
    2. C
    3. etc
- Compilador -> Baja de nivel de abstracción de nuestro código para llegar a los mnemónicos para que estos puedan comunicarse con el hardware
# ¿Qué es un compilador?
El compilador tiene como objetivo bajar de nivel y unificar archivos de alto nivel, como objetivo pasarselo al ensamblador para poder correr nuestro
programa
- Metaprograma (Programa que hace programas)
- Traductor
- Baja nivel de abstracción
- Existen muchos compiladores diferentes
También existe el proceso de vinculación donde se unifican los direferentes archivos que trabajan en conjunto para poder ejecutar el programa
